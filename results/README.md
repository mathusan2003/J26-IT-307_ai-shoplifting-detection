# Results

Place dissertation evidence here when the project produces it. The folders are in Git. Their contents are not, unless the team later agrees to commit a specific small file.

## Folders

| Path | What to put here |
| --- | --- |
| `screenshots/` | Interface or pipeline stills for the report |
| `videos/` | Demo clips |
| `reports/` | Exported tables, charts, or short result summaries |

Generated JSON from each module stays in that module's `outputs/` folder during development. Copy only the items you need for the written report into `results/`.

Do not store model weights or full datasets here.
